# Asma — Quran & Sunnah for Women

High-end mobile app design mockup (5.5" × 3" at 600 DPI) showing four screens:
welcome, home, Quran (surah strand), and hadith reader.

- `asma-mockup.png` — final rendered mockup (3300 × 1800)
- `asma-mockup.svg` — editable vector source
- `index.html` — working interactive prototype (open in any browser, no install needed)
